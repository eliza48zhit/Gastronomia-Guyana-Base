🇬🇾 Gastronomia de Guyana - Smart Contract (Base Mainnet)
Este es el vigesimosegundo contrato inteligente de mi coleccion profesional "Sabores de America". Guyana es el hogar del Pepperpot, un plato que desafia el tiempo gracias al Cassareep, un jarabe negro y espeso extraido de la mandioca amarga. Este contrato introduce la variable tecnica de Tipo de Cassareep, documentando el ingrediente que permite la preservacion inmutable de la comida, tal como la blockchain preserva estos datos.

📖 Modo de Uso

Consultar el Pepperpot: En la pestaña Read Contract, usa consultarPlato (ID 1) para verificar como el Cassareep artesanal es la base del primer registro.

Registrar Tradicion: En la pestaña Write Contract, usa registrarPlato para añadir iconos como "Cassava Bread" (Base Yuca) o "Labba Pepperpot".

Votacion Publica: Califica tus sabores favoritos de Guyana mediante el sistema de Likes y Dislikes directamente en la blockchain.
